Research projects

HyPowerFlow

A GPU-parallel power flow solver for many grid scenarios at once. It uses data compression, structured hyper-sparsity and better initial voltage-angle estimates, so it needs less memory and fewer iterations to converge.

  • Python
  • PyTorch Geometric
  • Patent pending
GitHub →

Identifying IBR control modes

A real-time, three-pronged supervised learning approach that uses micro-PMU data to identify inverter control modes and estimate IBR and load parameters, with adaptive window selection. Tested on the IEEE 13-node feeder.

  • Python
  • Random forest
  • IEEE TIA 2024
Read the paper →

Security-constrained dispatch

Security-constrained unit commitment for the IEEE 73-bus system with Benders decomposition, covering transmission and generator contingencies and renewable variability.

  • AMPL
  • Gurobi
GitHub →

Julia EMT simulation library

A Julia library for electromagnetic transient simulation of power systems, tested on the WECC 240-bus system.

  • Julia
  • EMT
